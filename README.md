# EmissiSense

Build a complete, professional, modern web application called **CarbonSense**.

CarbonSense is a B.Tech final-year project for **carbon-emission estimation, solar-generation forecasting, explainable AI, and scenario-based sustainability analysis**.

The website should look like a serious academic/research-grade software product that can be demonstrated to a B.Tech project evaluation committee. It should NOT look like a generic template, startup landing page, or simple CRUD dashboard.

## 1. TECHNOLOGY

Use:

* React
* TypeScript
* Vite
* Tailwind CSS
* shadcn/ui
* Recharts or another suitable charting library
* Lucide icons
* Responsive design
* Clean component-based architecture

Use reusable components and keep the code organized so that a Python/ML backend can be connected later.

For the first version, use realistic **demo/mock data** where the real ML backend is not yet connected.

IMPORTANT:

* Do NOT fabricate real model accuracy or research results.
* Clearly mark demo values as "Demo Data" wherever appropriate.
* Keep all model metrics, emission factors and carbon-credit assumptions configurable.
* Structure the application so the demo data can later be replaced by API responses from the CarbonSense Python/ML backend.
